# AItest — uCoz AI site stack

Готовый стек Cursor для создания и управления сайтами uCoz через MCP и agent skills.

## Быстрый старт

1. MCP уже в `.mcp.json` → `https://www.ucoz.com/mcp`  
2. Skills в `.cursor/skills/` (все 9 из [каталога](https://www.ucoz.ru/ai/skills))  
3. Workflow: см. [AGENTS.md](AGENTS.md)

Авторизация: Settings → Tools & MCP → `ucoz-mcp` → Authenticate (вход в uCoz → «Разрешить»).

Инструкции: [подключение MCP к Cursor](https://www.ucoz.ru/help/razrabotka-api/podklyuchenie-ucoz-mcp-k-cursor) · [как работает MCP](https://www.ucoz.ru/ai/mcp#how-it-works)
