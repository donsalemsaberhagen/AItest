## Principles borrowed (not copied)

- Dual layer: commerce HTML always available; WebGL is progressive enhancement
- Few concurrent animations; scroll owns camera; cursor owns micro-parallax
- Hotspots → categories, not decorative stickers
- Reduced-motion + mobile lite path
- Studio lighting language: dark void, controlled speculars, no particle spam

## Rights

No Arthur assets, models, footage, or code are reused. TOPMANSHOPWORLD showroom uses an original stylized vehicle (procedural meshes) + native uCoz shop.
